# Баг из слов

Telegram-бот помогает начинающему тестировщику уточнить обстоятельства ошибки и собрать проверяемый черновик баг-репорта. Архитектура отделяет бизнес-логику от Telegram и использует SQLite и OpenAI-compatible API.

## Запуск на локальном компьютере

Нужен Python 3.11 или новее. Создайте бота через BotFather и получите ключ выбранного LLM API, совместимого с Chat Completions.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните в `.env` `TELEGRAM_BOT_TOKEN`, `LLM_API_KEY`, `LLM_API_BASE_URL` и `LLM_MODEL`, затем запустите:

```bash
python main.py
```

На Windows активируйте окружение командой `.venv\\Scripts\\activate`. Для непрерывной работы компьютер должен быть включён, подключён к интернету и не переходить в сон. Для пилота отдельно проверьте запуск после перезагрузки и восстановление из резервной копии файла SQLite.

## Сценарий MVP

- `/start` показывает меню; «Новый баг» начинает один диалог об одной ошибке.
- Бот принимает текст до 4000 символов, отклоняет распространённые форматы паролей и ключей, задаёт уточнения максимум в пяти раундах.
- «Не знаю» фиксирует отсутствие сведений; можно досрочно сформировать отчёт.
- Поля можно исправить, результат выдаётся в чате и файлом Markdown.
- История доступна только самому пользователю в Telegram. «Удалить историю» удаляет пользовательскую запись, сессии, сообщения и отчёты из локальной SQLite. Истечение срока хранения очищается раз в час.
- Ограничение по умолчанию — 30 обращений к модели за час на пользователя.

## Настройки

См. `.env.example`. Параметры API задаются отдельно от логики бота. Адаптер ожидает endpoint `/chat/completions` и ответ JSON в `choices[0].message.content`. На генерацию отводится до 30 секунд, включая одну скрытую повторную попытку.

## Данные и ограничения

Диалоги и черновики хранятся локально в `data/bugizslov.sqlite3` не дольше 14 дней. Их текст отправляется Telegram и настроенному LLM-провайдеру. Не используйте реальные пароли, токены или персональные данные в пилоте. Удаление из SQLite не удаляет сообщения из истории Telegram или возможные копии у LLM-провайдера.

Секретный шаблонный фильтр снижает риск случайной передачи распространённых форматов, но не может обнаружить все секреты. Перед приглашением пользователей настройте автозапуск, резервное копирование, ответственного за восстановление и проверьте доступность на протяжении 48 часов.
